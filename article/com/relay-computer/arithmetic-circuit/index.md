## 演算回路の理論

$N$ 入力 $M$ 出力の演算回路全体の集合を $(2^N-> 2^M)$ と表す。

### 構成

演算$F={f_1,f_2dots.h}$を組み合わせて、ある演算$f$を構成可能であることを、${f_1,f_2dots.h} -> f$と表す。

### 完備性

1. ${"NOR"} -> {"AND", "OR", "NOT"}$

2. ${"AND", "OR", "NOT"} -> {(2 -> 2)}$

3. ${"AND", "OR", "NOT", (2^N -> 2)} -> {(2^(N+1) -> 2)}$

$F in (2^(N+1) -> 2)$ の真理値表

| $I_1$ |       | $I_N$ | $I_(N+1)$ | $O$   |
| ----- | ----- | ----- | --------- | ----- |
|       |       |       | 0         | $O^1$ |
|       | $I^1$ |       | 0         | $O^1$ |
|       |       |       | 0         | $O^1$ |
|       |       |       | 1         | $O^2$ |
|       | $I^2$ |       | 1         | $O^2$ |
|       |       |       | 1         | $O^2$ |

$$
F^1(I^1_1dots.h I^1_N) = O^1 \\
F^2(I^2_1dots.h I^2_N) = O^2
$$

$$
F(I_1dots.h I_N , I_(N+1)) = F^1(I_1dots.h I_N) dot.op overline(I_(N+1)) + F^2(I_1dots.h I_N) dot.op I_(N+1)
$$

1~3 より、

$$
{"NOR"} -> forall N {(2^N -> 2)}
$$

### 演算回路

ある演算の集合 $F={f_1,f_2dots.h}$ をすべてを構成可能な、演算集合 $F_e$ を、（$F$に対する）基本演算集合という。

演算回路を作るということは、目的とする演算 $f$ を、

1. 演算としてふるまう系を探す
2. それらを組み合わせて
3. あ

このような特性を持つ現象を見つけたら、

ある種の「演算」を行っている

さらに、その系の入力を操作できる場合、「演算回路」を作ることができます。

### 回路サイズ

演算 $f$ に必要な基本演算数を評価したい。

### 演算時間

演算 $f$ に必要な時間を評価したい。

一般に演算時間は入力によって変化するので、入力 $a$ に対する演算時間を $T(f,a)$ とする。

入力の確率分布を $P(a)$ としたとき、演算時間の期待値を $T(f,P)=sum P(a)T(f,a)$ とする。

特に、一様分布に対する演算時間の期待値を $macron(T)(f)$ とする。

## 群演算器

群 $(2^N,compose)$

### Prefix Sum

入力列 $a_0,a_1dots.h.c a_(n-1)$ に対して出力列

$$
s_i = a_0 compose a_1 compose a_2 dots.h.c compose a_i
$$

を返す演算器を構成する。

$s_i$ を逐次に求めると $n$ 段必要だが、PrefixSum を使うと $ceil.l log n ceil.r$ 段で済ませることができる。
